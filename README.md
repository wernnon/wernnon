# Olá, eu sou o Wernnon!

### Desenvolvedor Full-Stack | Estagiário na SMTI | React • Node.js • TypeScript

Sou um desenvolvedor apaixonado por transformar ideias complexas em código limpo e criar soluções digitais eficientes. Atualmente, atuo como Estagiário de Desenvolvimento pela Superintendência Municipal de Tecnologia da Informação (SMTI) de Porto Velho, RO. Busco constantemente desafios que me permitam construir projetos de alto impacto e aprimorar minhas habilidades.

- **Foco Técnico:** Especialista no ecossistema JavaScript/TypeScript, construindo desde interfaces dinâmicas até APIs robustas, com foco na **criação de agentes autônomos**.
- **O que estou fazendo:** Desenvolvendo o sistema de gestão esportiva *Construindo Campeões* (serviço público da Prefeitura de Porto Velho) e ferramentas para otimizar o fluxo de trabalho de devs, como o *Dev Automation Kit*.
- **Aberto a:** Colaborações em projetos open-source, novos desafios e oportunidades na área de engenharia de software.

## Projetos em Destaque

**[Dev Automation Kit](https://alanclimaco.github.io/dev-automation-kit-web/)**
Aplicativo desktop colaborativo criado para preparar contexto de código para IAs (estimativa de tokens e higienização) e executar diagnósticos automáticos em bases de código, otimizando o tempo e a produtividade do desenvolvedor.

**Construindo Campeões**  
  Sistema de gestão esportiva desenvolvido como serviço público para a Prefeitura Municipal de Porto Velho (SMTI), voltado para a organização e acompanhamento de iniciativas esportivas municipais.

**[WLW_RESERVE](https://github.com/wernnon/WLW_RESERVE)**  
  Sistema desenvolvido em **TypeScript** com o propósito de gerenciar o agendamento e a reserva de espaços para eventos.

**[Template TypeScript API](https://github.com/wernnon/template_typscript_api)**  
  Boilerplate e estrutura base em **TypeScript** desenvolvida para agilizar o setup e a padronização na criação de APIs backend.
